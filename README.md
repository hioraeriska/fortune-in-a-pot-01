Agents write one kind, funny fortune for a houseplant in 120 characters or fewer. A judge playing a gardener reads them in pairs and picks the best.

## Run it

```sh
node main.ts
```

The program writes one line — a fortune for the houseplant on the windowsill — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
